# Responsive Navbar

Bài thực hành tạo thanh điều hướng (navbar) responsive bằng HTML, CSS (Flexbox, Media Queries) và JavaScript.

## Tính năng
- **Desktop**: Hiển thị đầy đủ thanh điều hướng nằm ngang.
- **Mobile** (màn hình <= 768px): Tự động ẩn danh sách điều hướng và hiện biểu tượng menu hamburger (☰).
- Nhấn vào biểu tượng ☰ để bật/tắt (toggle) danh sách liên kết điều hướng.

## Cấu trúc thư mục
- `index.html`: Cấu trúc trang web và thanh điều hướng.
- `style.css`: Định dạng giao diện, hiệu ứng và cấu hình Media Query responsive.
- `script.js`: Xử lý sự kiện click vào nút menu để hiển thị/ẩn menu trên thiết bị di động.
